# Tasky - Task Management Solutions

Tasky is a [cohesive repository](https://github.com/astorDev/hesive/tree/main/repos), which means that it's not dedicated to a specific tool, but rather anything, related to a particular theme. In this case, task tracking and project management.

## Tasky Modules

Each sub-theme (module) in the repository also covers a particular topic. The list of topics is supposed to grow freely. For now we have:

- [📁 markdown](./markdown/README.md): Investigates Using Markdown for Task Tracking
- [📁 roadmap-concept](./roadmap-concept/README.md): proposes a roadmap-based naming for task groups.
