# Tasky Future

## Values

The list below tries to describe with values (feature) a perfect task management solution should have. In other words, what qualities Tasky would embody:

> 🚧 The list is a **Work In Progress**. It's **almost definitely** incomplete or requires restructuring

- Frictionless Adding/Editing/Planning (Minimal Context Switching from User)
- Always Accessible for both Editing & Processing (Accessible Accross Desktop & Mobile)
- Focused Processing (You can immediately see the tasks picked for attention right now)
- Seemless (Easy-to-set, accessible accross devices) Reminders
- Cross-Contextual Work (Can see both Global and Focused Picture, depending on situation)
- Integretable: Can be easily plugged to AI and other external systems
