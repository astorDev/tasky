# Markdown for Task Tracking

This module is about markdown files as a "database" format for a task management solution.

## Benefits

Even without any help of this module, markdown has many good qualities, separating it from a classical project management solutions / databases:

- Streamlined editing
  - No issue level/type concerns
  - Free-format structuring
  - All in one doc
  - "Free" attributes addition
- Git-Friendliness
  - Wonderful Review Support
  - Advanced History Support
- AI-Nativeness
- No Vendors

## Drawbacks

Naturally, markdown has a set of drawbacks too. Essentially one of the goals of the module is to address this problems one by one and try to find a solution for each (or decide that it wasn't a problem to begin with 😄)

- No built-in assignment mechanism
- No built-in intermediary status management e.g. no mechanism for `In Progress`
  - No Kanban boards
- No built-in automation engines.
- No Advanced Queries
