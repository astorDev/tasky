# Markdown as a Task Tracker

> How to Use Markdown as Your Core Project Management Solution

![Bye Jira, I Will NOT Miss You!](thumb.png)

Perhaps, everyone has filled a TODO list at least ones. Although, figuring out what is to be done, might have been challenging, the structure was likely as clear as the day. And in the end, you'll get a rather clear overview without any additional effort.

However, when we people start using a "sophisticated" tooling, like Jira, suddenly setting up the infrastructure becomes a challenge on it's own. Out of the blue, one have to think about task types, metadata and the other stuff before even writing a task description. Perhaps, that's the reason, that even teams with Jira subscriptions resort to using Excel, Miro and everything else when doing high-level planning instead of Jira. 

In this article, we'll investigate how markdown can bring the simplicity back, while also giving a couple of other perks.

## TLDR;

Markdown provides you a very simple way of editing your task list: No need to care about task types and levels, Nesting is easy, you can format it however you want. Since it's a document format it's free-forever and as portable as it gets. Finally, the format is AI-Native and agents can work with it without any additional setup.

It might not be ideal for team work, since we can't immediately notify other team members about changes in task assignment or status. Still, most of the time markdown can be a good initial canvas for the task, that later get into a classical task management solution.
