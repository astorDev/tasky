# Tasky Frogs

Frogs are tasks that are especially painful to tackle. They are typically characterized by:

- Vague steps and a volatile number of steps required for completion.
- A need for some sort of uninteresting investigation.
- Not typically being part of a bigger narrative.
- Dependence on some person or institution.

Those are the types of tasks that are procrastination magnets.

This module investigates how those tasks can be addressed to minimize their damage, or potentially how to strategically convert them into something that is not so painful.
